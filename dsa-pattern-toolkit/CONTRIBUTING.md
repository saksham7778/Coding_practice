# Contributing

Thanks for helping improve DSA Pattern Toolkit!

## Good first contributions

- Add a focused algorithm with a clear invariant and complexity analysis.
- Add regression tests for a reported edge case.
- Improve an explanation or runnable example.
- Improve portability or CI without adding unnecessary dependencies.

## Pull request checklist

- [ ] Explain the problem and the proposed solution.
- [ ] Include tests for normal and edge cases.
- [ ] Document time and space complexity.
- [ ] Build with CMake and run CTest locally.
- [ ] Keep the change focused and avoid unrelated formatting changes.

Please do not submit generated code without reviewing it and validating correctness.
